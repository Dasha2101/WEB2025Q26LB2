# To-Do List

Мини-проектик для списка задач - их можно добавлять (с датой), перетаскивать, отмечать выполненными и удалять.

## Возможности

- поиск задач по названию
- фильтр по статусу выполнения
- сортировка по дате
- ручное изменение порядка задач перетаскиванием
- сохранение списка (задачи остаются после перезагрузки страницы)
- адаптивное отображение на узком экране

## Порядок задач

Можно через drag and drop, если выбрать параметр "Вручную", тогда порядок сохраняется вместе с задачами. Можно сортировать по дате - либо сначала ближайшие, либо сначала поздние.
